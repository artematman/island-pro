# Установка Island Pro

1. Скачайте `Island-Pro-for-macOS-2.1.dmg` в разделе **Releases**.
2. Откройте DMG и перетащите **Island Pro** в **Applications / Программы**.
3. Запустите Island Pro — никаких команд в Terminal и обходов Gatekeeper не требуется.

Нужен Mac с Apple silicon и macOS 15 или новее. Приложение подписано Developer ID и нотарифицировано Apple.

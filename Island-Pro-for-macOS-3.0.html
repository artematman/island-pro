Island Pro 3.0

Большое обновление интерактивной чёлки для macOS.

  • Скриншоты теперь отображаются ровными квадратными карточками, не перекрываются и удаляются отдельно.
  • Исправлен запуск из Dock и восстановление панели после полного закрытия.
  • Сохранены улучшения энергоэффективности: адаптивные фоновые проверки, кэширование музыки и экономный режим ожидания.
  • Добавлен защищённый канал обновлений. Island Pro сообщит о следующих версиях и предложит установить их.

Обновление подписано Developer ID и проверено службой нотариализации Apple.

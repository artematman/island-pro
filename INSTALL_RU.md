# Установка Island Pro

1. Скачайте `Island-Pro-for-macOS-3.1.dmg` из этого репозитория.
2. Откройте DMG и перетащите **Island Pro** в **Applications / Программы**.
3. Запустите Island Pro — никаких команд в Terminal и обходов Gatekeeper не требуется.

Нужен Mac с Apple silicon и macOS 15 или новее. Приложение подписано Developer ID и нотарифицировано Apple.

Начиная с версии 2.1 Island Pro проверяет подписанный канал обновлений не чаще одного раза в сутки. Новая версия не устанавливается молча: приложение показывает описание и предлагает пользователю обновиться. Для немедленной проверки используйте «Настройки → Проверить обновления».

В версии 3.1 появилась вкладка «Ссылки»: важные сайты можно хранить под рукой и открывать системным либо выбранным в настройках браузером.

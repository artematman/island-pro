# Island Pro

Official releases, signed update feed and release notes for **Island Pro** — an interactive MacBook notch with Music, Calendar, Pin, Screens, Clipboard and offline-capable system Translation.

## Install

1. Download `Island-Pro-for-macOS-2.1.dmg` from **Releases**.
2. Open it and drag **Island Pro** into **Applications**.
3. Launch Island Pro. macOS verifies the Developer ID signature and Apple notarization automatically.

Requirements: Apple silicon Mac, macOS 15 or later.

## Updates

Island Pro 2.1 and later checks this repository's signed `appcast.xml` at most once per day. Every update is protected by EdDSA, Developer ID, Hardened Runtime and Apple notarization. Automatic installation is disabled; the user always chooses whether to install.

## Privacy

No analytics or telemetry. The update checker does not send a system profile. This repository intentionally contains release artifacts and public release metadata only — application source code is maintained separately.
